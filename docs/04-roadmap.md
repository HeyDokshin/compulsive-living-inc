# 04 · План разработки

Принцип: каждый этап заканчивается **играбельным билдом**, и каждая механика сразу пишется как плагин через SDK. Если для новой механики приходится лезть во внутренности `engine` — значит, в SDK не хватает точки расширения, и сначала добавляем её.

Отметки: `[ ]` не начато · `[~]` в работе · `[x]` готово.

---

## Этап 1 · Воксельный мир ✅
**Результат:** сгенерированный остров с террасами, реками и пляжами, по которому летает камера.
- [x] Чанки 16×H×16, палитра блоков (стабильные номера для сохранений), реестр блоков
- [x] Реестр текстур: процедурные паттерны (расширяются плагинами) + PNG из `content/<pack>/textures/`
- [x] Текстурный атлас из реестров, пересборка на лету
- [x] Greedy meshing + AO в Web Worker (пул воркеров, ближние чанки первыми)
- [x] Конвейер генерации как реестр `worldgen`: shape → rivers → ponds → surface → voxels (плагин `terrain`)
- [x] Свет по времени суток (кривые ключевых кадров в конфиге), солнце/луна
- [x] Оверлеи: сетка, границы чанков, атлас (`atlas`)
- [x] Живая настройка генератора: ползунки → остров перегенерируется
- [x] Мягкий стиль: пастельные текстуры, тонмаппинг, мягкие цветные тени, tilt-shift, виньетка, тёплая цветокоррекция
- [x] Один остров в мире 128×128: процедурная форма, но всегда одна суша и одинаковая площадь (`island.size`, по умолчанию 40% мира)
- [x] «Катящийся» мир: изгиб к горизонту; за краем мира — декоративный фон моря (не генерация)
- [x] Вода: поверхность ниже края блока, текстура плывёт
- [x] Декоративная флора: травинки и цветы покачиваются на ветру (плагин `flora`)
- Генерация идёт в главном потоке: шаги — функции плагинов, их нельзя передать в воркер. Остров 128×128 строится за ~20 мс; вынести в воркер можно позже, если миры вырастут.

## Этап 2 · Игрок ✅
**Результат:** персонаж ходит по острову, камера следует за ним.
- [x] Система ввода: действия ↔ клавиатура/мышь/геймпад (левый стик, кнопки `Pad0…`)
- [x] Движение относительно камеры, бег (Shift), плавный разворот
- [x] Коллизии с вокселями: скольжение вдоль стен, автоподъём на 1 блок, нельзя шагнуть с обрыва выше 1 блока или зайти в воду
- [x] Остров всегда проходим: генератор строит лестницы между террасами и мостики через реки (`terrain:paths`)
- [x] Камера плавно следует за игроком (`api.render.follow`)
- [x] Воксельные модели: текстовые слои в JSON5 + загрузчик MagicaVoxel `.vox`; риги из частей; перекраска палитры
- [x] Процедурная анимация двуногих: шаг, взмах рук, покачивание, дыхание (плагин `characters`)
- [x] Курсор клетки перед игроком + подсказка с названием блока, событие `player:target`
- [x] Видимость за препятствиями: мягкий силуэт персонажа сквозь рельеф (вместо срезания стен) + круглая тень
- [x] Доводка: близкая камера (зум 2.6, наклон 44°), плавный зум, взгляд вперёд по ходу движения; мягкий разгон и мгновенная остановка; солнечные и тенистые пятна на газоне

- [x] Инструменты: лопата копает и закапывает ямки; топор, сачок, удочка, лейка — заглушки до своих этапов (плагин `tools`)

- [x] Сервисы между плагинами (`api.services.provide/get`), инвентарь доступен как `items:inventory`
- [x] Предмет в руке персонажа, анимации взмаха и подбора, подсказка «Space · действие»

## Этап 4 · Сохранения ✅
**Результат:** игра сохраняется и загружается; при запуске продолжается последний остров.
- [x] IndexedDB (метаданные отдельно от данных), 3 слота, автосохранение каждые 2 мин и при сворачивании вкладки
- [x] Мир сохраняется целиком (RLE, ~десятки КБ) вместе с палитрой: сейв не зависит от генератора и модов
- [x] Сущности сохраняются по постоянным компонентам, uid сохраняются; неизвестные компоненты удалённых модов не теряются
- [x] `api.save.register({ version, save, load, migrate })` для данных плагинов; данные отсутствующих плагинов сохраняются как есть
- [x] Версия формата файла + цепочка миграций (`engine/save/migrations.ts`)
- [x] Загрузка = чистый перезапуск сессии: плагины выгружаются и стартуют заново поверх сохранённого мира (`api.save.loaded`)
- [x] Меню по Esc: сохранить, слоты (загрузить / перезаписать / удалить), новый остров, экспорт и импорт файлом
- [x] Доводка: ямки нужно обходить (хук `movement:blocked`), крупнее инструменты в руке и спрайтовые иконки, панель F2 скрыта по умолчанию
- [x] Звук: синтезированные звуки в реестре `sounds` (шаги по поверхности, копание, подбор, взмах, брызги, интерфейс), каналы громкости
- [x] Частицы: реестр `particles` (пыль при беге, комья земли, искорки, блики у предметов на земле, брызги)
- [x] Мышь: клетка под курсором с учётом изгиба мира, клик — дойти по A*-пути и сделать действие
- [x] Ревью: разбит `Game.ts`, исправлены зависания очереди генерации и мешера, проверка импорта сейвов с откатом, горячие пути без аллокаций, строгий TS без неиспользуемого кода
- [x] Производительность: пресеты качества (низкое / среднее / высокое), FPS-счётчик, настройки в меню (Esc → Настройки)
- [x] Запуск без сервера: `npm run play` → один файл `dist/index.html`, открывается двойным кликом
- [x] Редактор внешности (C): причёски и цвета; варианты — данные в реестре `wardrobe:options` (плагин `wardrobe`)
- [x] Музыка и природа: генеративная музыка (день/ночь), прибой у воды, птицы днём, сверчки ночью (плагин `ambience`)
- [x] Обучение первых минут: 7 шагов в реестре `tutorial:steps`, прогресс в сейве, можно пропустить (плагин `tutorial`)
- [x] Доводка по скриншоту: камера ближе (зум 4, максимум 6), tilt-shift слабеет на близком зуме, инструменты держатся за рукоять (`held.grip`), высокие предметы лежат на земле, вода в прудах и реках почти вровень с берегом

## Этап 5 · Природа и время ✅
**Результат:** живой остров, который меняется по дням и сезонам.
- [x] Часы игры (`TimeService`): реальное время устройства (как в уютных островных играх) / ускоренное / замороженное; путешествие во времени (`time 18:30`, `time +3d`)
- [x] События `time:hour`, `time:day`, `time:season`; дни, прошедшие без игрока, проигрываются после загрузки (до 30); часы в HUD
- [x] Календарь и сезоны (оба полушария), свет следует за часами
- [x] Погода (плагин `weather`): ясно, облачно, дождь, снег зимой — детерминированно по сиду и дню; свет, осадки, звук дождя, хук `light:adjust`
- [x] Деревья (плагин `nature`): яблоня, персик, апельсин, дуб; потрясти → фрукты, топор → 3 полена в день, посадить фрукт или саженец → растёт по дням, выкопать молодое; сезонные кроны
- [x] Камни (до 5 ударов в день: камень, железо) и места раскопок каждый день (окаменелости)
- [x] Цветы (плагин `garden`): тюльпаны, космеи, розы; сорвать, посадить, посеять, полить; политые (или под дождём) соседи скрещиваются — генетика в данных
- [x] Острова из старых сейвов засеиваются автоматически (`api.save.hasData`)
