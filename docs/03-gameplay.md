# 03 · Геймплей

**Compulsive Living** — уютная социальная песочница на воксельном острове в изометрии. Игрок живёт в реальном времени: собирает ресурсы, ловит рыбу и насекомых, обустраивает дом и остров, знакомится с жителями. Нет проигрыша, есть ежедневный ритм и долгосрочные цели.

Все названия ниже — рабочие и свои. Каждая механика = отдельный плагин (в скобках).

## Основной цикл

```
день начинается → проверить остров (что выросло, кто пришёл, что в магазине)
   → собирать / ловить / копать → продавать / жертвовать / крафтить
   → обустраивать дом и остров → общаться с жителями
   → получать прогресс (деньги, рецепты, дружба, новые здания) → завтра будет новое
```

## Механики

### Базовое (`core`)
- Движение по клеточной сетке (свободное, с привязкой взаимодействий к клетке перед игроком).
- Инвентарь со слотами и стаками, быстрые инструменты (колесо инструментов).
- Предметы на земле, подбор, выбрасывание.
- Курсор клетки и подсказка действия («Копать», «Потрясти», «Поговорить»).

### Природа (`nature`)
- Деревья: трясти (фрукты, иногда что-то неожиданное), рубить (дерево), выкапывать и пересаживать.
- Фрукты как саженцы — свой фрукт острова + привозные.
- Цветы: посадка, полив, **скрещивание цветов → новые окраски** (генетика в данных).
- Камни: бить — ресурсы, раз в день.
- Раскопки: метки на земле → окаменелости/сокровища.
- Сорняки, рост травы, следы на траве (опционально).

### Время, сезоны, погода (`time`, `weather`)
- Реальное время, 4 сезона, полушария.
- Погода: ясно, облачно, дождь, снег, радуга, звездопад — влияет на спавн видов.
- Освещение и музыка меняются по часам.

### Коллекции (`fishing`, `bugs`, `museum`)
- **Рыбалка**: тени рыб в воде, размер тени — подсказка, мини-игра поклёвки.
- **Насекомые**: появляются на цветах, деревьях, камнях; подкрадывание, сачок.
- Каждый вид — запись в данных: сезон, часы, погода, место, редкость, цена, размер тени.
- **Энциклопедия** пойманных видов и **музей**, куда виды жертвуются и выставляются в залах.

### Экономика (`shop`, `economy`)
- Валюта (рабочее название — «ракушки»).
- Магазин: ежедневно меняющийся ассортимент, продажа предметов.
- Ящик для продажи (продаётся на следующее утро).
- Динамические цены для отдельного товара (рынок с колебаниями внутри недели).
- Кредит на дом → расширение дома.

### Крафт (`crafting`)
- Верстак, рецепты-открытки (находятся, покупаются, даются жителями).
- Рецепты в данных, используют теги ингредиентов.
- Кастомизация: варианты окраски предметов.

### Строительство и декор (`housing`, `terraform`)
- Дом игрока: интерьер с сеткой, размещение мебели (поворот, слои: пол / стены / на столе / ковры), обои и полы.
- Мебель на улице — на любой клетке острова.
- Терраформинг: поднять/опустить скалы, прокладывать реки, дорожки (паттерны блоков).
- Расширение дома: этажи, комнаты.

### Жители (`villagers`)
- NPC с **характерами** (данные: тип речи, хобби, предпочтения подарков, распорядок).
- Распорядок дня: дома/гуляет/занимается хобби/спит.
- Диалоги — данные с условиями (время, погода, дружба, события) и переменными.
- Дружба: разговоры, подарки, просьбы. Фото на высоком уровне дружбы.
- Переезды: новые жители приезжают, старые иногда хотят уехать.
- Жители сами взаимодействуют с миром (ловят рыбу, поливают цветы — через ту же матрицу взаимодействий).

### Задания и события (`quests`, `events`)
- Ежедневные мини-задания («поймай 3 рыбы») → очки → награды.
- Достижения.
- Календарные праздники и сезонные события (данные: даты, декор, NPC-гость, особый магазин).
- Гости острова: странствующие торговцы, учёный и т. п.

### Развитие острова (`island`)
- Рейтинг острова (деревья, цветы, мебель, разнообразие) → открывает новое.
- Постройки: музей, магазин, мост, лестница — через «проекты» с ресурсами.

### Позже / опционально
- Путешествия на случайные острова-ресурсы (процедурная генерация).
- Гости по сети (визиты к другу), обмен предметами.
- Фоторежим, дизайнер паттернов (рисование текстур).
- Мобильное управление.
