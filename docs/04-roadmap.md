# 04 · План разработки

Принцип: каждый этап заканчивается **играбельным билдом**, и каждая механика сразу пишется как плагин через SDK. Если для новой механики приходится лезть во внутренности `engine` — значит, в SDK не хватает точки расширения, и сначала добавляем её.

Отметки: `[ ]` не начато · `[~]` в работе · `[x]` готово.

---

## Этап 1 · Воксельный мир ✅
**Результат:** сгенерированный остров с террасами, реками и пляжами, по которому летает камера.
- [x] Чанки 16×H×16, палитра блоков (стабильные номера для сохранений), реестр блоков
- [x] Реестр текстур: процедурные паттерны (расширяются плагинами) + PNG из `content/<pack>/textures/`
- [x] Текстурный атлас из реестров, пересборка на лету
- [x] Greedy meshing + AO в Web Worker (пул воркеров, ближние чанки первыми)
- [x] Конвейер генерации как реестр `worldgen`: shape → rivers → ponds → surface → voxels (плагин `terrain`)
- [x] Свет по времени суток (кривые ключевых кадров в конфиге), солнце/луна
- [x] Оверлеи: сетка, границы чанков, атлас (`atlas`)
- [x] Живая настройка генератора: ползунки → остров перегенерируется
- [x] Мягкий стиль: пастельные текстуры, тонмаппинг, мягкие цветные тени, tilt-shift, виньетка, тёплая цветокоррекция
- [x] Один остров в мире 128×128: процедурная форма, но всегда одна суша и одинаковая площадь (`island.size`, по умолчанию 40% мира)
- [x] «Катящийся» мир: изгиб к горизонту; за краем мира — декоративный фон моря (не генерация)
- [x] Вода: поверхность ниже края блока, текстура плывёт
- [x] Декоративная флора: травинки и цветы покачиваются на ветру (плагин `flora`)
- Генерация идёт в главном потоке: шаги — функции плагинов, их нельзя передать в воркер. Остров 128×128 строится за ~20 мс; вынести в воркер можно позже, если миры вырастут.

- [x] Тело персонажа мягче: у частей рига своё скругление (`round` у модели части сильнее рига); дальше упирается в форму самих моделей — голова нарисована кубом 8×8×7, по-настоящему круглого персонажа даст только новая модель
- [x] Иконки предметов рисуются самими моделями (`render/IconRenderer`): мягкие рёбра, плоские ковры сверху, материалы, без кривизны мира; инструменты — по диагонали; в интерфейсе без пиксельного масштабирования

## Этап 15 · Комнаты дальше
**Результат:** на острове можно зайти не в два здания, а во все, и они разные.
- [ ] Лавка — помещение: полки с товарами дня, прилавок, лавочница за ним; покупка — подойти к вещи
- [ ] Дома жителей: у каждого свой дом, обстановка по характеру (обои, пол, набор мебели — данные), можно постучать и зайти, когда хозяин дома
- [ ] Несколько комнат в доме: мансарда на третьем уровне и пристройки, двери и лестница между комнатами (движок уже умеет переходить из комнаты в комнату)
- [ ] Размер комнаты из её описания (сейчас до 16 × 16)
- [ ] Свет от мебели: лампы и торшеры дают пятно света на полу и стенах, как окна
- [ ] Звук помещений: дождь по крыше приглушённо, тиканье, если на стене часы, шаги гулче в музее, своя музыка дома и в музее

## Этап 16 · Жизнь острова
**Результат:** на острове интересно и через месяц: соседи помнят игрока, год идёт по сезонам.
- [ ] Дружба с жителями: уровни, любимые и нелюбимые подарки, письма в почтовом ящике, просьбы и ответные подарки
- [ ] Больше соседей: 8 → 16, новые характеры, переезды
- [ ] Коллекции: 39 → около 80 видов по сезонам и часам; рецепты: 12 → около 40; праздники на весь год, включая зимние
- [ ] Сезоны на земле: снег на острове зимой, лёд у берега, листопад осенью, цветение весной
- [ ] Ночь: светлячки, звёзды отражаются в воде

## Этап 17 · Устройства и игроки
**Результат:** в игру удобно играть на планшете и телефоне, а не только с клавиатуры и геймпада.
- [ ] Сенсорное управление: касание — идти, долгое касание — красться, щипок — зум, кнопки действий на экране
- [ ] Интерфейс под палец: крупные цели в окнах и в телефоне игры
- [ ] Установка со страницы игры как приложение, работа без сети
- [ ] Перевод: тексты контента и интерфейса по ключам, английский как второй язык
