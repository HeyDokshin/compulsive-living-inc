# Compulsive Living

Уютная социальная песочница на воксельном острове в изометрии: воксельный мир, реальное время, сбор, рыбалка, коллекции, обустройство дома и острова, жители-соседи.

Стек: **TypeScript + Vite + three.js + miniplex (ECS) + Preact**. Управление: WASD или мышь, Space — действие, I — карманы, R — инструмент, B — энциклопедия, T — эмоции, F4 — редактор контента, Esc — меню (сохранения, настройки). Вся игра собрана из плагинов поверх публичного SDK, контент описывается в JSON5.

## Запуск

**Играть без сервера:** соберите игру один раз, и дальше открывайте `dist/index.html` двойным кликом. Всё (код, воркеры, контент) лежит в этом одном файле, он работает по `file://` и его можно кому-нибудь переслать.

```bash
npm install
npm run play       # = npm run build && open dist/index.html
```

**Отдельным приложением (macOS 13+):** окно без браузера, на системном WebKit — ни Chromium, ни Electron не нужны, весом около 3 МБ. Нужны Xcode Command Line Tools.

```bash
npm run app        # = npm run build + dist/Compulsive Living.app
```

Сохранения приложения свои, отдельно от браузера (перенести — «Острова» → Экспорт / Импорт). При выходе остров сохраняется сам.

**Сеть:** погода в игре настоящая — примерный город берётся по IP (ipwho.is, geojs.io), прогноз у [Open-Meteo](https://open-meteo.com) (CC BY 4.0, бесплатно для некоммерческого использования). Выключается в «Настройки → Остров», без сети у острова своя погода.

**Разработка** (горячая перезагрузка плагинов, контента и конфигов, сохранение настроек из панели F2 в файлы):

```bash
npm run dev        # http://localhost:5173
npm test           # юнит-тесты
npm run typecheck
npm run lint       # oxlint: ошибки, слои, циклы импортов
npm run check      # всё сразу: линтер, типы, тесты
```
